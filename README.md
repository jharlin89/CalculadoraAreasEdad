## 2. Descripción del programa

Este proyecto consiste en una aplicación de consola desarrollada en el lenguaje de programación C#, que permite realizar cálculos matemáticos y verificar la mayoría de edad de una persona.

El programa cuenta con un menú principal donde el usuario puede seleccionar diferentes opciones para realizar las operaciones disponibles.

## 3. Datos de entrada

El programa solicita los siguientes datos al usuario:

- Base y altura para calcular el área de un triángulo.
- Longitud del lado para calcular el área de un cuadrado.
- Radio para calcular el área de un círculo.
- Edad de una persona para verificar si es mayor o menor de edad.
- Número de opción seleccionado en el menú principal.

## 4. Procesos que realiza el programa

El programa utiliza funciones para realizar cada operación:

- **Área del triángulo:** multiplica la base por la altura y divide el resultado entre dos.
- **Área del cuadrado:** multiplica el lado por sí mismo.
- **Área del círculo:** multiplica PI por el radio elevado al cuadrado.
- **Verificación de edad:** comprueba si la edad es igual o superior a 18 años para determinar si la persona es mayor de edad.

También utiliza estructuras condicionales y un ciclo repetitivo para mantener el menú disponible hasta que el usuario seleccione la opción de salir.

## 5. Datos de salida

El programa muestra en pantalla:

- El área calculada del triángulo.
- El área calculada del cuadrado.
- El área calculada del círculo.
- Un mensaje indicando si la persona es mayor o menor de edad.
- Mensajes de orientación cuando se seleccionan opciones incorrectas o se introducen valores no permitidos.
- Un mensaje de despedida al salir del programa.
